# Instalación Proyecto Reservas Resort Islantilla

- - Pagina index de mi aplicación: http://127.0.0.1:8000/home

- Lista de Endpoints de mi ReservaController y de UsuariosController

## Reservas

1. GET http://127.0.0.1:8000/reservas
2. GET http://127.0.0.1:8000/reservas/new
3. POST http://127.0.0.1:8000/reservas/new
4. GET http://127.0.0.1:8000/reservas/{id}
5. GET http://127.0.0.1:8000/reservas/{id}/edit 
6. POST http://127.0.0.1:8000/reservas/{id}/edit
7. POST http://127.0.0.1:8000/reservas/{id}
8. GET http://127.0.0.1:8000/reservas/Json{id}
9. GET http://127.0.0.1:8000/reservas/Json2_{id}   


## Usuarios

1. GET http://127.0.0.1:8000/usuarios
2. GET http://127.0.0.1:8000/usuarios/new
3. POST http://127.0.0.1:8000/usuarios/new
4. GET http://127.0.0.1:8000/usuarios/{id}
5. GET http://127.0.0.1:8000/usuarios/{id}/edit 
6. POST http://127.0.0.1:8000/usuarios/{id}/edit
7. POST http://127.0.0.1:8000/usuarios/{id} (delete)
